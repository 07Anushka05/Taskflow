## ✨ Features

- 📝 **Add, edit & delete** tasks effortlessly
- 🚦 **Priority levels** — Low, Medium, High
- ⏰ **Due date reminders** with modal & banner alerts
- 🔍 **Search & filter** — All / Active / Completed
- 🧹 **Clear completed** tasks in one click
- 📊 **Live task counter** for what's remaining
- 📱 **Fully responsive** — works great on mobile
